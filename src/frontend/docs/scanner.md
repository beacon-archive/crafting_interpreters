# scanner

scanner 是扫描器，也叫做词法分析器。它接收一个字符序列，逐一分析其中的字符，依据**最长匹配(maximal munch)**原则来将这些字符组成一个词素，并分析这些词素代表的含义(token type)，将其整体组合为一个 token，并输出，交由后续的分析器使用。


## lexme 词素

词素就是原始字符串的一个子串，我们按照**最长匹配原则**来获取的一个**有意义的子串**，这个子串就叫做词素。词素本身代表的含义，由 token type 进行体现，并最终组合成为一个解析器可用的 token。


## token type

在 Lox 中，每一个 token 都有其对应的类型，方便解析器进行后续处理(直接调用对应的函数，不必再分析 token 的含义)。token 主要有如下几类：

1. 字面量: 标识符、字符串、数字
2. 关键字
3. 布尔值: true，false
4. 空值: nil


## Identifier 标识符

标识符是由下划线或字面开头的一个连续不为空的数字字母下划线组成的字符串，正则表达式的描述:`[a-zA-Z_](a-zA-Z_0-9)*`，一个标识符的 token type 为: IDENTIFIER.



## Keywords 关键字

关键字是标识符的一个子集，对于一个标识符，首先会判断其是否位于关键字集合中，如果位于，那么它的 token type 将会设置为对应的关键字: AND, CLASS...等等。
